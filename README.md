# 分组随手存

为 Windows 版三星浏览器制作的 Chromium 扩展。自动记录普通窗口中的标签分组，并在分组关闭后在书签栏放置对应的恢复入口。点击书签或扩展弹窗中的分组，可以重新打开网页并建立同名、同色分组；恢复成功后对应的书签和弹窗条目消失，再次关闭分组时重新出现。

## 安装

1. 在三星浏览器打开扩展管理页面（菜单中的“扩展程序”，或尝试地址 `chrome://extensions`）。
2. 打开“开发者模式”，选择“加载已解压的扩展程序”，选择本目录。
3. 显示书签栏，并将扩展图标固定到工具栏。创建分组并等待同步，然后关闭分组，确认其出现在书签栏和扩展弹窗中。

在扩展弹窗中，左键或中键点击分组都会在新窗口恢复，不会导航或关闭当前标签页。

## 注意

- 仅保存安装并启用扩展后观察到的分组，不能找回安装前丢失的内容。
- 快照在分组变化后约一秒更新。创建、编辑或恢复分组后，请等待约一秒或在弹窗点刷新后再关闭；浏览器突然退出时最后的更改可能来不及保存。
- 数据保存在浏览器本机扩展存储中，不上传服务器。卸载扩展会删除这些数据，书签也将无法恢复分组；不要将扩展数据或含敏感网址的书签分享给他人。
- 不保存无痕窗口。部分内部页面或受限制地址可能无法恢复。恢复的是网址，不包含未提交的表单、页面状态或历史记录。
- 书签在后台标签页打开时（例如浏览器设置为中键后台打开），分组会恢复到新窗口。
- 左键点击书签会先由浏览器在当前标签页打开恢复页面。扩展会在新窗口恢复分组，并尝试返回原页面；原页面可能重新加载，未保存的内容可能丢失。若没有可返回的历史记录，恢复页会保留。使用扩展弹窗可避免导航原标签页。
- 删除已保存分组会删除其对应书签；手动删除书签也会删除对应的已保存分组。书签只能在安装本扩展且拥有对应本地数据的浏览器配置中使用。
- 需要浏览器实现 Chromium 的 `tabGroups`、`tabs`、`bookmarks` 和 Manifest V3 API；不同三星浏览器版本可能存在兼容差异。
